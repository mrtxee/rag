# Отчет о построении эмбеддингов

### Какая база знаний

За основу фантазийного мира взята вселенная мультсериала «Рик и Морти».

База знаний о фантазийном вселенной представляет собой 85 документов, в котором было произведено 166 замен из термов с учетом морфологии. Язык русский. Средний размер документа ~ 4000 символов, ~ 600 токенов. Уникальных слов всего ~ 5300.

### Выбор эмбеддинг-модели

**Требования к системе**
- Локальный запуск
- On-perm система: Intel Core i5, 16 BG RAM, No-GPU
- Контекст ≥ 512 токенов
- Бесплатная лицензия

#### Решение

Для прикладной задачи оптимальным выбором будет **intfloat/multilingual-e5-large-instruct** т.к.:
* Бесплатная
* Поддержка русского языка
* Оптимальное потребление ресурсов под систему
* Размер контекста (512 токенов) сопоставим с размером документ (до 600 токенов)

#### Чанкинг

В индексе получилось 224 чанка.
Средний размер документа (истории) 600 токенов, поэтому задан размер чанков 400 символов, с оверлапом 50. Оверлап важен, для сохранения контекста при переключении между несколькими чанками при поиске в индексе.

#### Генерация индексов

Для хранения выбран векторная база данных ChromaDB.
Преимущества: как унитарное решение, которое позволяет хранить индекс, данные, векторное представление токена и метаданные в единой системе.

Генерация индекса на 85 документами 224 чанка заняла 218 секунд
