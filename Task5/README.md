## 3. Опасные вопросы боту с защитой

### Управление рисками

При внедрении политики безопасности были учтены следующие риски
1. Атака через инструкции в документе
2. Утечка данных через ошибку модерации входящего потока документов в базу данных
3. Генерация запрещенного контента большой языковой моделью

Меры по снижению рисков
1. Внесены правки в Системный промпт
	- Новый системный промпт в явном виде запрещает
		- выполнять инструкции пользователя или документов
		- отправлять или генерировать чувствительные данных
	- Данная мера радикально снижает риск атаки через инструкции языковой модели
2. Добавлена проверка найденных чанков перед их передачей  языковой моделей. Если чанк содержит подозрительный, либо запрещенный контент – он будет передан в LLM.
	- Данная мера минимизирует риск утечки данных через ошибочный документ
3. Перед отдачей пользователю готового ответа, происходит пост-провеврка на предмет выявления запрещенного контента. 
	- Данная мера снижает риск нежелательного поведения LLM
4. Снижена температура LLM для повышения точности ответов и снижения числа галлюцинаций модели
	- Данная мера снижает риск нежелательного поведения LLM
