# Объяснение knowledge_base

За основу фантазийного мира взята вселенная мультсериала «Рик и Морти», а именно описание сюжетов из https://rickandmorty.fandom.com/

При помощи серии python-скриптов сделано следующее
1. Просканированы и скачаны все страницы, содержащие сюжет эпизода или биографию персонажа
2. Экстрагированы сюжеты всех серий и биографий основных персонажей в форме markdown файлов
3. Составлен список всех личных наименований в скачанных текстах с градацией по частоте упоминания
4. На выходе сгенерирована база знаний (knowledge_base)
	1. База знаний о фантазийном вселенной в 85 документах
	2. Словарь замен из 166 термов с учетом морфологии
